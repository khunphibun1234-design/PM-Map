# PM-Map — แผนที่ 3D โรงเรียนพิบูลมังสาหาร (CU-TEP Exam Venue Map)

แผนที่ 3 มิติของโรงเรียนพิบูลมังสาหาร สำหรับให้ผู้เข้าสอบ CU-TEP ดูสนามสอบจริง (หอประชุมราษฎร์รังสรรค์)

- `index.html` — แผนที่พร้อมใช้งาน ไฟล์เดียว (three.js r160 จาก CDN, ตัวละครและภาพฝังในไฟล์) เปิดในเบราว์เซอร์ได้เลย
- เลือกตัวละคร นักเรียนชาย / นักเรียนหญิง ก่อนเข้าเล่น
- ปุ่ม **ไปสนามสอบ CU-TEP** เดินอัตโนมัติจากประตูหน้าไปยังห้องสอบในหอประชุมราษฎร์รังสรรค์
- ปุ่ม **เดินชมโรงเรียน** เดินชมรอบโรงเรียน, จอยสติ๊ก / W A S D เดินเอง

## Source (`src/`)
- `layout_v2.py` — ผังอาคาร ถนน ลาน (พิกัดเมตร x = ตะวันออก, z = ใต้)
- `build_terrain_v2.py` — สร้าง heightmap / splatmap / layout.json
- `template_v2.html` — ตัวแสดงผล three.js
- `build_page_v2.py` — รวมทุกอย่างเป็น `index.html` (ต้องมีไฟล์ assets: albedo, โลโก้, ตัวละคร .glb)
